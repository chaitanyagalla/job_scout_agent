# Job Scout Frontend

Next.js UI for the FastAPI/ADK backend in the repository root.

## Run locally

1. Start the backend from the repository root:

```powershell
.\\.venv\\Scripts\\python.exe main.py
```

2. Start the frontend:

```powershell
cd frontend
npm install
npm run dev
```

3. Open `http://localhost:3000`.

Copy `.env.example` to `.env.local` if your backend URL, ADK app name, or local user id differ.
